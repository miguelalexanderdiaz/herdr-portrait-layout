Platforms

Developed and used on macOS. Linux and Windows are described from reading the code; nothing here claims a test run that did not happen. The pure-logic tests are written to run on all three systems, but no test can show the layout in a live Herdr window.

Notes

  • The nvim socket lives in /tmp on purpose: unix-socket paths are limited to about 104 bytes, and the per-user temporary folder on macOS plus a long home path can exceed that.
  • nvim is started through your login shell so that it finds the same PATH as your terminals. The PATH is read once with printenv PATH, which works in bash, zsh and fish.
  • Paths shown with ~ use Herdr's home(), so Linux and Windows home folders shorten too.
  • Key names use Herdr's spelling. ctrl-alt- combinations are avoided because Windows treats them as AltGr.
