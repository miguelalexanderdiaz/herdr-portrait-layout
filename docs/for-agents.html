For agents

If you are a coding agent asked to install, adapt or change this layout, read AGENTS.md first. This page is its summary. A machine-readable index is llms.txt.

Before you install, tell the person

  • No mod uses the network.
  • They run: sh (or powershell on Windows) to list folders, git for change marks, hc run and hc read, and nvim through the login shell.
  • They read the folder of the focused pane, one file when alt-clicked, and the screen text of blocked or finished agents while the waiting list is open.
  • They write data/portrait-tree-spines/*.svg in the Herdr home folder and nvim sockets under /tmp.

Install steps

  1. Read RECIPE.md, AGENTS.md and every file before writing.
  2. Copy layouts/* and each folder of mods/ into the Herdr home folder. Never overwrite. If a name is taken (the person's or Herdr's), rename the new one: file or folder, the mod names in the layouts, the mods/<name>/ paths inside the mod, the keys sections.
  3. If the person already has attention-picker, keep theirs and skip the bundled copy.
  4. Merge keys.json; ask before replacing a key they already use.
  5. herdr-app check <absolute folder> for every mod, then layout.switch to portrait. Their own layout stays; ctrl-shift-l switches back.

Rename checklist

  • A layout file: the keys section layout:<name> and the layout.switch:<other> values.
  • A mod folder: its own mods/<name>/ asset paths in svg() and image() calls, and the mod name in the layouts. For attention-picker, the constant PICKER in bar-strip.
  • Never rename the ids bar, panel, panel-body, vault.

Editing safely

  • Do not write into a live Herdr home from a script in a checkout: every save reloads on the person's screen at once. Work in a scratch copy selected with HERDR_APP_HOME.
  • Do not drive someone's running app (herdr-app do, shot, status) without asking.
  • mods/attention-picker is a bundled copy. Change it in the herdr-agents-waiting repository.
  • The three cloned_from mods are copies of Herdr 0.1.12 mods and are never updated by Herdr.
  • Tests: node --test (no argument); herdr-app check on each mod; the scripts in scripts/.
