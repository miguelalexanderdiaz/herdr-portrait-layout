Install

macOS and Linux

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-portrait-layout/main/install/install.sh | sh

Windows (PowerShell)

irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-portrait-layout/main/install/install.ps1 | iex

It shows what the mods reach and asks before writing anything. It backs up whatever it replaces, merges your keys.json, checks each mod with herdr-app check and, the first time, switches to the portrait layout. Running it again updates.

Needs Herdr 0.1.12 or newer. Built and used on macOS; Linux and Windows should work but have not been run.

Remove it: the same command with the uninstall flag. It removes only what it installed, and only the keys you have not changed since.

curl -fsSL https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-portrait-layout/main/install/install.sh | sh -s -- --uninstall
$env:HERDR_UNINSTALL = 1; irm https://raw.githubusercontent.com/miguelalexanderdiaz/herdr-portrait-layout/main/install/install.ps1 | iex
With an agent

Tell a terminal agent inside Herdr:

install https://github.com/miguelalexanderdiaz/herdr-portrait-layout

It reads every file first and tells you what the mods run and read. It never overwrites (a taken name is renamed), asks before changing your keys.json, checks each mod and switches to the layout. The steps it follows: For agents.

By hand

Copy the files into your Herdr home, the folder on the last line of herdr-app --help (~/.config/herdr-app on macOS; HERDR_APP_HOME overrides it). Nothing that already exists is overwritten.

git clone https://github.com/miguelalexanderdiaz/herdr-portrait-layout.git
cd herdr-portrait-layout
H="${HERDR_APP_HOME:-$HOME/.config/herdr-app}"
mkdir -p "$H/layouts" "$H/mods"
for f in layouts/*; do
  if [ -e "$H/$f" ]; then echo "exists, rename first: $f"; else cp "$f" "$H/layouts/"; fi
done
for m in mods/*; do
  n="${m#mods/}"
  if [ -e "$H/mods/$n" ]; then echo "exists, skip or rename: $n"; else cp -R "$m" "$H/mods/$n"; fi
done
for m in mods/*; do herdr-app check "$H/mods/${m#mods/}"; done
herdr-app do layout.switch --name portrait

On Windows (not yet run on a Windows machine):

git clone https://github.com/miguelalexanderdiaz/herdr-portrait-layout.git
cd herdr-portrait-layout
$H = if ($env:HERDR_APP_HOME) { $env:HERDR_APP_HOME } else { Join-Path $HOME ".config\herdr-app" }
New-Item -ItemType Directory -Force "$H\layouts", "$H\mods" | Out-Null
foreach ($f in Get-ChildItem layouts) {
  if (Test-Path "$H\layouts\$($f.Name)") { "exists, rename first: $($f.Name)" }
  else { Copy-Item $f.FullName "$H\layouts\" }
}
foreach ($m in Get-ChildItem mods -Directory) {
  if (Test-Path "$H\mods\$($m.Name)") { "exists, skip or rename: $($m.Name)" }
  else { Copy-Item $m.FullName "$H\mods\$($m.Name)" -Recurse }
}
foreach ($m in Get-ChildItem mods -Directory) { herdr-app check "$H\mods\$($m.Name)" }
herdr-app do layout.switch --name portrait

Then add the sections of the repository's keys.json to yours (or copy it if you have none), keeping your own binding where a key is taken. The keys are listed on Configuration.

To remove it by hand: switch to another layout (ctrl-shift-l), delete layouts/portrait*.json and .svg and the mod folders you copied, remove the keys you added, and delete data/portrait-tree-spines/ and data/portrait-viewer/.

Options, name clashes and checks
  • No questions: sh -s -- --yes (Windows: $env:HERDR_YES = 1; before irm). A key you already use is then kept.
  • Another Herdr home: sh -s -- --home <folder>, or set HERDR_APP_HOME.
  • From a clone: install/install.sh or .\install\install.ps1. The scripts are short: install/.
  • Keys: on macOS and Linux the merge needs Node, or on macOS the system's own JavaScript; without either the script prints the keys to add by hand.
  • Backups go to community/herdr-portrait-layout/ in the Herdr home. Removing leaves data/portrait-tree-spines/ and data/portrait-viewer/ there; delete them if you like.
  • Name clashes: the script keeps your own attention-picker and replaces only its own mods and layouts. By hand, rename the new thing, never yours: the rename checklist lists what must change with it.
  • Check it worked: every herdr-app check passes, and the window shows the strip (Search, Add machine, Settings) with the tab bar under it. If not, layout.error in the Herdr home says why, and ctrl-alt-shift-escape puts the default layout back.
