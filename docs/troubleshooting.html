Troubleshooting

Start with the escape hatch and the status, then the list below.

  • ctrl-alt-shift-escape always works: it sets the shown layout and keys.json aside and returns to Herdr's default layout.
  • herdr-app status lists what the window shows and any errors. Herdr also writes layout.error and keys.error files in its home folder when a file is invalid, and keeps the last good version.

The layout does not load or looks wrong

Open layout.error in the Herdr home folder. A missing mod name in the layout or a JSON slip shows there. If you renamed a mod, the mod names in the layout and the mods/<name>/ paths inside the mod must be renamed with it.

The waiting-list key does nothing

The key (ctrl-shift-j by default) runs mod.open:attention-picker. It is bound in the two layout sections of keys.json, so it does nothing in another layout, or if you renamed the layout without renaming the keys section. It also needs a mod named attention-picker in mods/; if you renamed it, change the key. Look for keys.error in the Herdr home folder. The bell's tooltip names the key that is really bound. If you bound bar-strip.attention or bar-strip.jump yourself instead, those reach only a bar-strip that is shown, so they do nothing while the bar is hidden.

A click opens the wrong thing, or “Couldn't open …”

  • Pick the editor with the ▾ in the Files header. It lists only editors on the PATH of your login shell (and, on macOS, apps in /Applications or ~/Applications); test with $SHELL -lc 'command -v nvim'. An editor you just installed shows up within a minute.
  • “Showing a read-only preview”: the default app is picked and the file is a script, which its system app could run; the preview opens instead. Pick an editor.
  • “Couldn't open nvim” (or another editor): hc run failed (the message has its error), or the terminal did not show up within 10 seconds (the layout ends it and names it).
  • “Not opened”: the file is a program (.exe, .app, an installer); the Files panel never starts programs.
  • A PDF shows only its first page, or a hint: install Poppler (brew install poppler, apt install poppler-utils, scoop install poppler).
  • A picture or PDF outside your home folder opens in the system's app: Herdr mods can only read inside the home folder.

Files says “No folder” or “No files”

The focused pane has no folder (for example a mod pane) and the space has none either. Focus a terminal pane. A line saying the list is limited means a folder had more than 500 entries or the total passed 5,000.

Files shows no marks

Marks come from git status in the focused folder. They are missing outside a git work tree, when git is not on the PATH, or on a machine where git failed.

A folded space's name is blank for a moment

The rotated name is an image written on first use under data/portrait-tree-spines/; the strip redraws once the file exists. If it stays blank, check that the Herdr home folder is writable.

Columns are cut off

Each column needs 290 px. With more spaces than fit, arrow markers appear at the ends; click them, swipe sideways, shift-scroll, or fold spaces. You can also widen the bar by dragging its divider.

The colours look wrong

The layout uses whatever theme Settings has chosen. Pick another theme, or pin one in the layout (see Configuration). The six space marks are fixed colours; on a light theme the active folded space's name is darkened toward the text colour, and the result has not been seen on a real light theme. Configuration says what was measured.

A mod did not update after I saved it

A broken save keeps the old version running. Run herdr-app check <folder> for the exact error, and herdr-app status.

Still stuck

Open an issue at github.com/miguelalexanderdiaz/herdr-portrait-layout/issues and fill in the form: what you did, what you expected, what happened, your Herdr version (herdr-app --version), your operating system, which layout you use (portrait or portrait-bottom), how you installed it, the shell you log in with, and the output of herdr-app check for the mod involved. Do not paste screenshots of your windows or file paths that include your name.
