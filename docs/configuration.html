Configuration

The layout pins nothing about your look. Everything below is a choice you make in your own Herdr home folder.

Theme

Neither layout sets a theme, so the theme you chose in Settings applies. Every Herdr theme names the same colours, so any shipped or user theme works. The chrome, text and state colours come from the theme: foreground, background, muted, dim, chrome, raised, hover, selected, border, accent, working, blocked, done and idle. The Files panel also takes its git-mark and preview-syntax colours from the theme's terminal palette (ansi1 to ansi6).

What is not themed:

  • The space marks. The six names Herdr gives spaces (ansi1 to ansi6) are drawn as six fixed colours in portrait-tree, the same on every theme. A colour set with space.colors as #rrggbb is used as written.
  • The letter on a mark's badge is white or near-black, chosen for each colour by contrast; it measures about 5.5 to 6.6 to 1 on all six marks, so it is readable on any theme.
  • The mark colour is also the 2 px rule under a space's name and, on the active folded space, the colour of its rotated name. As text on a light background the six marks measure only 2.3 to 3.4 to 1 (computed against white and two light greys, not against a real theme). So when Herdr reports a light theme, that rotated name is mixed halfway toward the theme's text colour, which brings it to at least 4.5 to 1 for text colours from black to dark grey (a test checks the arithmetic). The badge and the rule keep the plain mark colour. How this looks on Herdr's light theme paper has not been seen by the author of this page; check it yourself.

Two ways to make a look a fixed part of the layout, both optional:

  • Pin one of Herdr's shipped themes, one for light and one for dark system appearance. In the layout file add to the root object: "theme": { "light": "paper", "dark": "graphite" }.
  • Carry your own theme file in themes/<name>.json in the Herdr home folder (see Herdr's reference for its fields) and name it in the same theme field.

The layout root can also override single theme colours, for example "colors": { "accent": "#ff8800" }; name theme colours (chrome, canvas) rather than hex when the look should work in light and dark.

The look this layout was designed with used a personal theme that is not part of this repository and not needed. The illustration on the Overview page uses the default Herdr colours.

Keys

The repository's keys.json, row for row. cmd-b is for macOS only; on Linux and Windows cmd is the Super or Windows key, which the system usually keeps, so expect it to do nothing there (not tried) and use ctrl-shift-g; the ctrl-shift keys are meant to work everywhere (on Linux and Windows that is expected from Herdr's key reference, not tested). The bell's tooltip prints the key actually bound for the waiting list on your machine.

layout:portrait-bottomctrl-shift-jmod.open:attention-pickerOpen or close the Agents waiting list, with its search box

mod.open:attention-picker opens the bundled Agents waiting dialog by name, so it works while the bar is hidden; pressing the key again closes it (this is what Herdr's reference says mod.open does; it has not been confirmed in the app yet, and going back to bar-strip.attention is a one-line change in your keys.json). The key is bound inside the two layout sections so it does nothing in other layouts. The layout's own mod commands stay available for anyone who bound them: bar-strip.attention (the same list) and bar-strip.jump (what a plain click on the bell does). Herdr delivers a mod command only to a copy that is shown, so those two do nothing while the bar is hidden. mod.open needs the attention-picker mod to be installed under that name.

To rebind, change the key on the left in your own keys.json. If you rename a layout, rename its section (layout:<name>) too.

Optional: tmux-style chords

If you like a prefix, this set uses ctrl-b then a letter. It is not shipped because a bound ctrl-b prefix takes ctrl-b away from the programs in your terminals (readline's back-one-character, and tmux's own prefix). Chords are not described in Herdr's written reference; this form is what the author used on macOS with Herdr 0.1.12. After saving, look for keys.error in the Herdr home folder.

{
  "layout:portrait": {
    "ctrl-b a": "mod.open:attention-picker",
    "ctrl-b b": "layout.toggle:bar",
    "ctrl-b shift-b": "layout.switch:portrait-bottom"
  },
  "layout:portrait-bottom": {
    "ctrl-b a": "mod.open:attention-picker",
    "ctrl-b b": "layout.toggle:bar",
    "ctrl-b shift-b": "layout.switch:portrait"
  }
}

Renaming

If you rename a layout or mod, see the rename checklist.

Layout ids the mods look up by name, which must not change: panel, panel-body, files and changes (children of panel-body). bar is named only by the toggle key layout.toggle:bar, so a rename needs the key changed with it. If you rename files or changes you also change the defaults in portrait-tabs (enabledPanels). RECIPE.md has the full list of load-bearing names.
