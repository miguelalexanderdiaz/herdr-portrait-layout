Privacy and side effects

Nothing in this repository uses the network: no fetch, no socket, no telemetry. Nothing leaves your machine because of this layout. What follows is everything the mods read, run and write, so you can decide before installing.

Mod by mod

bar-strip

Reads
Agent list and status, the layout tree, the key bindings (to print the bell's key), whether an app update is ready, and whether the file mods/vault/main.js exists in the Herdr home folder (existence only, at start and every 60 seconds).
Runs
Nothing. Opens Herdr's own dialogs and runs Herdr commands (agent.focus, layout.select, layout.show, layout.hide, mod.open, app.settings).
Writes or stores
Shared key mods.vault (a yes or no).
Where to check
probeVault, keyHint, attention, picker

portrait-tree

Reads
Spaces, the list of machines (to keep a remote machine's saved state while it is loading or offline), tabs, panes, agents and their state, whether the theme is light, terminal labels (editor.file), shared keys space.colors and vault.panes.
Runs
Nothing.
Writes or stores
The mod's local storage: folded and peeked (space ids, dropped when the space is gone and its machine is ready) and changed (agent address and the time its state last changed; an agent that is gone loses its entry after 7 days). Shared key agents.since. One small SVG per space name under data/portrait-tree-spines/ in the Herdr home folder (the rotated name on a folded space); files of names that no longer exist are deleted once when the tree starts.
Where to check
track, reveal, createSpineStore, pruneChanged

portrait-tabs

Reads
Spaces, the list of machines, tabs, panes, layout tree, window info.
Runs
Nothing.
Writes or stores
Local storage panels: which side panel each space last had open (dropped when the space is gone and its machine is ready).
Where to check
syncPanel, prunePanels

portrait-pane

Reads
The one pane it heads: program, folder, state, zoom.
Runs
Nothing.
Writes or stores
Nothing.
Where to check
render

portrait-files

Reads
Folder listings of the focused pane's folder (500 entries per folder, 5,000 in all), the git state of that folder, and the text of one file (up to 400,000 characters shown) when you alt-click it or pick the read-only preview.
Runs
sh to list a folder (macOS, Linux, remote machines), powershell on a Windows local machine, git rev-parse --show-prefix and git status (read-only flags, no lock), your login shell once per machine to read its PATH (printenv PATH), command -v for each editor it can offer (and, on macOS, a look for their apps in /Applications and ~/Applications), hc run to start a terminal editor in a terminal Herdr shows, the app you picked (open -a on macOS, its command elsewhere), and open, xdg-open or rundll32 to hand a document to the system's app (never a program). Nothing runs while the Files panel is closed.
Writes or stores
A socket file for each nvim it starts, in /tmp on macOS and Linux. Labels on an editor's terminal: editor.file (the full file path) and, for nvim, editor.socket; hc ls shows them. The shared keys files.editor (your editor choice) and files.request (the last Open with choice).
Where to check
directory, refresh, edit, detect, terminalEditor, loginPath, nvimArgv, show

nvim-float

Reads
Terminal list and labels, spaces, panes.
Runs
sh running nvim --server … --remote-send, --remote and --remote-expr against the socket of an nvim this layout started, only when you use its close button or Keep menu.
Writes or stores
Nothing.
Where to check
nvim, keptEditors

portrait-viewer

Reads
The picture or PDF you click in Files, only inside your home folder.
Runs
pdfinfo and pdftoppm (Poppler, when installed) to count and draw PDF pages; on macOS qlmanage (the first page without Poppler) and sips (the size of AVIF and TIFF pictures); stat or powershell for file dates; where or your login shell to find Poppler; open -a Preview, xdg-open or rundll32 when you press Open.
Writes or stores
Copies of the pictures and drawn pages under data/portrait-viewer/cache/ in the Herdr home folder; entries older than 30 days, and the oldest past 200 MB, are deleted.
Where to check
createViewer, image, pdfPage, prune, load

attention-picker (bundled)

Reads
Agent list and spaces; the shared keys agents.since (when portrait-tree publishes it) and space.colors. While the list is open, the last 60 lines of the screen of every agent that is blocked or done, read with hc read; only the last question or message line is kept and shown.
Runs
hc read for each blocked or finished agent, every 3 seconds, only while the list is open (the first read happens when it opens).
Writes or stores
Shared key attention.sort (the sort order you picked). Local storage attention.seen: for each agent, its address, its state group and the time the picker first saw it in that state; no screen text, and an agent that is gone is dropped.
Where to check
readPreviews, trackSeen, saveSeen

What this means in practice

  • Folders. The Files panel lists the folder of the pane you focus and reads one file's text only for the read-only preview (alt-click, or a click where nvim is unavailable). It does not read file contents otherwise. nvim, when it runs, reads the file itself.
  • Terminal text. Only the waiting list reads terminal screens, and only for agents that are blocked or done, and only while the list is open. It keeps one line per agent, in memory, and stores no screen text.
  • A visible label. An nvim started from Files carries labels with the full file path and the socket path. Any program or person who runs hc ls on the same machine can see them.
  • Files written. Spine images under data/portrait-tree-spines/ contain your space names and nothing else. nvim removes its socket in /tmp when it exits normally. The layout's mods and the waiting list keep small records in Herdr's local storage for a mod: fold state, state-change times, the open side panel per space, and attention.seen (above).
  • Agents. The programs you run in terminals do whatever they do. This layout does not add to it.

How to verify

  • Search the mods for network use: rg -n "fetch|XMLHttpRequest|WebSocket" mods prints nothing. (A search for http finds only the XML namespace string in SVG files and in one SVG template string.)
  • List what is run: rg -n "exec\(|hc\(" mods.
  • The repository contains scripts that scan every tracked file for home paths, e-mail addresses and tokens (see CONTRIBUTING.md).
