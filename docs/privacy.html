Privacy and side effects

Nothing leaves your machine because of this layout. In short:

Network
None. No mod calls the network; no telemetry.
Runs
sh or powershell to list folders; git (read-only) for the Files marks; your login shell once, for its PATH; the editor you pick or the system's opener (never a program); Poppler for PDFs; hc to start editors and, while the waiting list is open, to read the last 60 lines of blocked or finished agents. Nothing runs while Files is closed.
Reads
The focused pane's folder, the files you open (pictures and PDFs only inside your home folder), your key bindings, Herdr's spaces, tabs, panes and agents.
Writes
Under data/ in the Herdr home: space-name images and the viewer's cache (kept 30 days, at most 200 MB). nvim sockets in /tmp. Small records in Herdr's mod storage, such as fold state (an agent's entry goes 7 days after the agent is gone). An editor's terminal is labelled with the file path, which hc ls shows.

Verify: rg -n "fetch|XMLHttpRequest|WebSocket" mods prints nothing; rg -n "exec\(|hc\(" mods lists what runs.

Mod by mod

bar-strip

Reads
Agents and their state, the layout tree, the key bindings (to name the bell's key), whether an app update is ready, the side panels Herdr offers (workspace.panels).
Runs
Only Herdr's own dialogs and commands.
Where to check
keyHint, enabledPanels, attention, picker

portrait-tree

Reads
Spaces, machines, tabs, panes, agents, terminal labels (editor.file), space.colors.
Stores
Mod storage folded, peeked (space ids) and changed (agent address and time; dropped 7 days after the agent is gone); shared key agents.since; one SVG per space name under data/portrait-tree-spines/, pruned when the tree starts.
Where to check
track, reveal, createSpineStore, pruneChanged

portrait-tabs and portrait-pane

Reads
Spaces, machines, tabs, panes, the layout tree, window info; the pane header reads only its own pane.
Stores
portrait-tabs: mod storage panels, the side panel each space last had open. portrait-pane: nothing.
Where to check
syncPanel, prunePanels, render

portrait-files

Reads
The focused pane's folder (500 entries per folder, 5,000 in all), its git state, and one file's text (up to 400,000 characters) when you alt-click it or pick the preview.
Runs
sh (or powershell on a local Windows machine), git rev-parse and git status (no lock), printenv PATH in your login shell once per machine, command -v per editor (on macOS also a look in the Applications folders), hc run for terminal editors, the app you picked, and open, xdg-open or rundll32 for documents.
Stores
An nvim socket in /tmp; terminal labels editor.file and editor.socket; shared keys files.editor and files.request.
Where to check
directory, refresh, edit, detect, terminalEditor, loginPath, nvimArgv, show

nvim-float

Runs
nvim --server … --remote-send, --remote, --remote-expr against an nvim this layout started, only from its close button or Keep menu.
Where to check
nvim, keptEditors

portrait-viewer

Reads
The picture or PDF you click, only inside your home folder.
Runs
pdfinfo and pdftoppm (Poppler); on macOS qlmanage and sips; stat or powershell for file dates; open -a Preview, xdg-open or rundll32 when you press Open.
Stores
Copies and drawn pages under data/portrait-viewer/cache/: older than 30 days, or the oldest past 200 MB, are deleted.
Where to check
createViewer, image, pdfPage, prune, load

attention-picker (bundled)

Reads
Agents, spaces, agents.since, space.colors; while the list is open, the last 60 lines of each blocked or finished agent's screen, keeping only the last question or message line, in memory.
Runs
hc read every 3 seconds, only while the list is open.
Stores
Shared key attention.sort; mod storage attention.seen (agent address, state group, first-seen time; no screen text).
Where to check
readPreviews, trackSeen, saveSeen
