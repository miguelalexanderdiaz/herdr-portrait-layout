How it works

A Herdr layout is a JSON tree of regions. Mods are small JavaScript programs that draw into the regions with native GPUI. This repository is two layout files and the mods they use. The build brief is RECIPE.md; this page is the map.

The layout tree

root (row)
  left (column, resizable divider)
    bar (column, 246 px high, chrome)   portrait: first child
      bar-strip   26 px   mod bar-strip
      tree                mod portrait-tree
    work (column, fixed)
      tabs        42 px   mod portrait-tabs   (drags the window)
      work-body (row, padding 8, gap 8)
        main              the active tab's panes, header mod portrait-pane
    bar ...                             portrait-bottom: here, before status
    status        28 px   shipped mod workspace-status
  panel (column, 368 px, hidden)
    panel-body (stack, active: files)
      files               mod portrait-files
      changes             shipped mod changes
      vault               optional, from snippets/vault-panel.json

The ids bar, panel, panel-body and vault are looked up by the mods and by the toggle key, so they must not change.

State and where it lives

  • Shared keys (Herdr keeps them in shared.json): agents.since, attention.sort, mods.vault. Read from Herdr or other mods: space.colors, workspace.panels, vault.panes.
  • Mod storage (per mod, kept by Herdr): fold state and recent state changes in portrait-tree, the per-space panel in portrait-tabs.
  • Files: only data/portrait-tree-spines/*.svg in the Herdr home folder, and nvim sockets under /tmp. Runtime files never go inside a mod folder, because Herdr reloads a mod whenever one of its files changes.

Why folded names are images

GPUI elements cannot be rotated, so a folded space's name is written once as a small SVG of rotated text, tinted with the current text colour, and drawn as an image. The first time a name is drawn it is written to disk and the strip redraws a moment later.

Hot reload

Herdr reloads a mod when any of its files is saved and keeps the old version if the new one is broken (herdr-app status shows why). A mod copy keeps running while hidden, so timers are conditional: the Files panel refreshes only while open, the waiting list polls only while open, the tree redraws every 30 seconds so its durations stay current.

Icons are carried inside each mod's folder, so a change to Herdr's own asset names does not break them. After a Herdr update, run herdr-app check on each mod again; the three cloned mods are copies of the 0.1.12 versions and are not updated by Herdr.
